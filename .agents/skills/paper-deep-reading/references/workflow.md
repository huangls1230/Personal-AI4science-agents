# Deep reading workflow

1. Inspect the authorized source, its hash, pages and extraction quality. An abstract or metadata alone has only that evidence scope. Treat detected sections and figure labels as unverified hints; distinguish physical and printed page numbers.
2. Read the overall research question, authors' stated motivation and claims, then prioritize sections needed for the user's goal. Check methods and assumptions, inputs/outputs, architecture and data/control flow; inspect actual diagrams and mathematical notation before explaining them. Flag extraction gaps or missing visual evidence.
3. For empirical work examine dataset, environment, baselines, metrics, procedures, main results, ablation and reproducibility where actually present. Adapt to theoretical and survey work instead of inventing experiments. Record a claim, evidence, location, strength, assumptions, alternative explanations and assessment. A verified locator only confirms a source location; it does not establish a claim is true.
4. Distinguish `[EVIDENCE]`, `[AUTHOR INTERPRETATION]`, `[AGENT INFERENCE]` and `[SPECULATION]`. Separate observed limits from suspected concerns and unresolved questions. Consider competing mechanisms and tests that could distinguish them; do not infer causality from correlation alone.
5. Classify one-paper observations and candidate gaps separately. A supported research gap requires independent cross-paper evidence; ask the parent to decide on further retrieval. Relate findings to the user's stated research only if context exists.
6. Prepare a Chinese Markdown reading note preserving the original paper title and precise terms. Follow `docs/literature-reading.md` for the supported template and output commands; keep personal notes untouched. Each verified quote must match actual extracted page text, and figures still require visual inspection. The user may manually import the file into Obsidian; do not use an Obsidian integration.
7. Mentor mode is optional: provide 1–3 reasoning questions if requested. Evaluate an actual user's response with evidence before proposing `research-verified`; send Citation a proposal only, with explicit approval for any future write.
