# 项目配置

这些文件是项目自定义配置，不是 Codex 的 `config.toml`。为避免 V0.1 引入 YAML 依赖，`.yaml` 文件使用同时属于 YAML 1.2 的 JSON 语法；用 Python 标准库 `json` 读取。角色由 `teams/` 描述，执行器、模型和路由是不同概念。配置的 `enabled` 只是许可，不证明运行时实际可用；路由必须与实际适配器注册和模型可用状态交叉核验。mock 仅用于离线测试，Codex 原生桥接、Pi 和 DeepSeek 未接入。

配置中的分值为相对偏好，不代表实际价格、速度或质量。`null` 表示未知，不是零。预算只对接入对应检查的本地执行路径有效；不能控制 Codex 账户的总用量。
