# Agent Group

团队仅按职责组织，不绑定模型或运行时；Literature 组与 Paper Editing 组已定义项目级子代理，实际发现和调用仍须按会话验证。

- `literature/`：文献检索、来源核查和证据整理。
- `research_execution/`：研究设计、计算与可复现实验。
- `paper_writing/`：AI Paper Editing Team，提供结构、术语与语言编辑建议。
- `critical_review/`：独立检验方法、证据及研究局限。
- `strict_review/`：严格审稿组初始化，分设方法、统计与复现、一致性和独立复核角色；参见[团队说明](strict_review/README.md)。

Codex 决定是否委派并最终验收，重要科研决策需人工批准。
